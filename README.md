# 🍔 UrbanEats - Premium Full-Stack Food Delivery Application

UrbanEats is a modern, high-performance food delivery platform built using the **MERN Stack** (MongoDB, Express, React, Node.js). This project features a minimalist "Apple-style" UI, secure Stripe payments in LKR, and a comprehensive Admin Dashboard.

---

## ✨ Key Features

- **Modern UI/UX:** Minimalist, non-italic design with a premium feel and smooth navigation.
- **LKR Currency Integration:** Fully optimized for the Sri Lankan market with LKR pricing.
- **Secure Payments:** Integrated **Stripe API** for handling secure online transactions.
- **Real-time Search:** Instantly find your favorite dishes with an optimized search bar.
- **Admin Dashboard:** A dedicated portal to manage inventory, track orders, and update statuses.
- **Responsive Layout:** Fully optimized for Mobile, Tablet, and Desktop views.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, React Router, Axios.
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB Atlas.
- **Authentication:** JWT (Authentication).
- **Payment:** Stripe API (LKR Support).
