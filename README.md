# 🍔 UrbanEats - Premium Full-Stack Food Delivery Application

UrbanEats is a modern, high-performance food delivery platform built using the **MERN Stack** (MongoDB, Express, React, Node.js). This project features a sleek minimalist UI, secure Stripe payments in LKR, and a comprehensive Admin Dashboard designed for professional order management.

---

## ✨ Key Features

- **Sleek & Professional UI:** A clean, high-end minimalist design focused on a seamless user experience.
- **LKR Currency Integration:** Fully optimized for the Sri Lankan market with LKR pricing and local delivery logic.
- **Secure Payments:** Integrated **Stripe API** for handling secure online transactions in LKR.
- **Real-time Search:** Instantly find your favorite dishes with an optimized search functionality.
- **Admin Dashboard:** A dedicated portal for store owners to manage inventory, track live orders, and update statuses.
- **Responsive Layout:** Fully optimized for Mobile, Tablet, and Desktop views to ensure accessibility everywhere.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS (Custom Premium Styling)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** JWT (JSON Web Tokens)
- **Payment:** Stripe API (LKR Support)
